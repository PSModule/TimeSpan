# TimeSpan

TimeSpan is a PowerShell module for working with TimeSpan values.

## Installation

Install the module from the PowerShell Gallery:

```powershell
Install-PSResource -Name TimeSpan
Import-Module -Name TimeSpan
```

## Documentation

Documentation is published at [psmodule.io/TimeSpan](https://psmodule.io/TimeSpan/).

Use PowerShell help and command discovery for module details:

```powershell
Get-Command -Module TimeSpan
Get-Help <CommandName> -Examples
```
